## Tasks

Each prompt is written in a curious user's voice. The result contract in the preamble adds two fields. `observables` is a list of `{label, x, ideal, measured}`. `ideal` means what a perfect quantum computer would give for the agent's own circuit. `values` is an object of named numbers. The contract defines each named number, so a lay prompt can stay lay.
